# Session End

Use this command to close out work cleanly.

Checklist:
1. Summarize what changed and why.
2. Note any files that still need follow-up.
3. Record tests run and tests not run.
4. Call out config, migration, or deployment implications.
5. Mention whether the change belongs only in `goforge-template` or also needs a matching `goforge-cli` template update.

Do not leave hidden assumptions:
- State if migrations are required.
- State if generated services need regeneration.
- State if the CLI templates are now out of sync.
