# GoForge Template

This is the default project template for [GoForge](https://github.com/mmycin/GoForge), a production-ready Go framework and CLI.

## Prerequisites
- Go 1.21 or later
- GoForge CLI

## Getting Started
This template is automatically used when you run `goforge new <project-name>`. For full documentation, visit the [GoForge Documentation](https://github.com/mmycin/GoForge/tree/main/goforge-cli/docs).

## Project Structure

```text
your-project/
├── boot/                        # Framework-owned bootstrap (do not edit)
│   ├── kernel.go                # Application lifecycle (NewApp, Start, Stop)
│   ├── client/                  # gRPC and HTTP client helpers
│   └── server/                  # HTTP & gRPC server, middleware
│       └── middleware/          # Recovery, logger, CORS, rate-limiter, error handler
│
├── core/                        # Framework packages — import freely, do not edit
│   ├── config/                  # Env/config loading (viper)
│   ├── database/                # DB connection and GORM wrapper
│   ├── errors/                  # Standardized AppError types (ErrNotFound, etc.)
│   ├── validator/               # Request validation (go-playground/validator)
│   └── console/                 # CLI command runner, logger, colors
│
├── internal/                    # Your code — everything here is meant to be edited
│   ├── services/                # Domain services
│   │   ├── kernel.go            # Auto-generated composition root (re-generated by CLI)
│   │   └── <name>/              # One directory per service
│   │       ├── handler.go       # HTTP handlers
│   │       ├── routes.go        # Route registration
│   │       ├── service.go       # Business logic
│   │       ├── model.go         # GORM model
│   │       ├── grpc.go          # gRPC server implementation
│   │       └── docs.go          # OpenAPI/Huma docs registration
│   ├── database/
│   │   ├── migrations/          # Atlas migration files
│   │   └── queries/             # Raw SQL queries (used by sqlc)
│   ├── proto/
│   │   └── <name>/              # Proto definitions + generated gRPC code
│   │       └── <name>.proto
│   └── tests/
│       ├── http/                # HTTP client tests
│       ├── grpc/                # gRPC client tests
│       ├── integration/         # Cross-layer integration tests
│       └── unit/                # Package-level unit tests
│
├── app/
│   └── main.go                  # Entry point
│
├── .env.example                 # Environment variable template
├── atlas.hcl                    # Atlas migration config
├── sqlc.yaml                    # SQLC codegen config
├── air.toml                     # Live-reload config (air)
└── Dockerfile                   # Container build
```

## Separation of concerns

| Directory | Who owns it | Editable? |
|-----------|-------------|-----------|
| `boot/`   | Framework   | No        |
| `core/`   | Framework   | No        |
| `internal/services/` | You | Yes — add handlers, models, routes |
| `internal/database/` | You | Yes — write migrations and queries |
| `internal/proto/`    | You | Yes — define proto services |
| `internal/tests/`    | You | Yes — write all tests here |

## CLI commands

```bash
goforge new <project>          # Scaffold a new project from this template
goforge gen:service <name>     # Generate a new service (handler, routes, model, docs, proto)
goforge rem:service <name>     # Remove a service and clean up kernel.go
goforge gen:migration <name>   # Generate an Atlas schema migration
goforge migrate                # Apply pending migrations
goforge gen:proto [name]       # Compile .proto files and generate gRPC stubs
goforge gen:sqlc               # Run sqlc code generation
goforge app serve              # Start the HTTP and gRPC servers
```
